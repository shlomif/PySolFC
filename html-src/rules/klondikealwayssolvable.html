Klondike (Always Solvable)

Klondike type. 1 deck. Unlimited redeals.

Object

Move all cards to the foundations.

Quick Description

Just like Klondike, except new deals are drawn from a pool of game numbers that have already been confirmed solvable (winnable with perfect play), so you should never get stuck with an unwinnable deal.

Notes

This only applies to fresh deals. If you manually enter a specific game number, that exact number is dealt as-is and is not guaranteed to be solvable.
