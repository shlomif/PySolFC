Settings and Options

PySol contains a lot of options allowing you to customize your game's look and feel, and experience. These are found in the Options menu of your menu bar. Note that depending on your installation configuration, or if you are running an Android/Kivy version, some of these options may not be available.

Player Options

You can change your player name. By registering multiple players, you can track statistics for multiple players playing on the same computer separately.

Additionally, there are options for whether we're tracking statistics, or if we want to confirm before ending an unfinished game.

Automatic Play

Automatic play options allow you to have certain moves play automatically, such as auto flip causing exposed cards to automatically flip face-up, and auto deal, which automatically deals cards from the talon when the waste is empty. Quick play enables the right mouse button shortcut.

The auto drop option allows cards to automatically move to the foundations when possible, though even if it's not set to run automatically, auto drop can still be manually triggered when needed. For more detail on auto drop, see Assist Options.

See How to use PySol for more details.

Assist Level

The assist level options allow you to enable or disable certain assist features, which causes their options to be grayed out, and keyboard shortcuts to not work.

The free hints option ensures that using hints does not disqualify the game from being counted as a win, though it would still not be counted as a perfect game.

You can also enable a stuck notification, so the game will notify you if there are no moves left.

There are other assist options that are game-specific, such as dealing all cards in Accordion type games or showing removed tiles in Mahjongg games. More info on these can be found with the rules of said games.

See Assist Options for more details.

Sound and Music

The sound and music dialog allows you to turn on and off music and sound samples, along with setting the volumes for the sounds. You can also toggle individual sound samples that should play or not.

Cards and Table

Cardset, Card Back, and Table Tile

You can change the cardset to change the look and feel of the individual cards. Different cardsets represent different decks of cards you can play with, and each can have a number of different possible card backs you can pick from.

You can also create custom cardsets from your own images - see cardset customization for more info on how.

The table tile controls the background of the table. You can set it to a solid color, or one of several loaded images. You can also import your own table tile images from your local files to use.

Card Size and Scaling

If your build supports card scaling, you can change the size of the cards. By default, auto-scaling is on, and the cards are scaled to match the screen size. But this can be switched to manual sizing, where you can use the default card size for the cardset, or grow or shrink them to your desired size. You can determine whether the aspect ratio should be preserved, or if the height and width can be resized separately, and if the auto scaling should apply in previews.

As an advanced option, you can change the resampling algorithm used to resize the cards.

Card View

The card view options control how the cards are displayed:

  • Card shadow - turns on and off the shadows on the moving cards
  • Shade legal moves - when moving cards, the destination stack is highlighted when you're about to move to a valid stack
  • Negative cards bottom - controls whether the empty stack images use the normal images (black borders) or the negative images (white borders)
  • Shrink face-down cards - face-down cards in stacks are compressed
  • Shade filled stacks - stacks that are completely filled are shaded
  • Compact long stacks - if a stack is extremely long, the cards will be compressed, so more will fit on the screen
  • Randomize card placement - there is some slight randomization of the positions of the cards, creating a slight scatter effect.

Game Layout

These options affect how the game and window are laid out:

  • Fullscreen - toggles fullscreen mode (also toggled with F11)
  • Spread stacks - spreads the stacks evenly across the screen
  • Center layout - sets the core layout to be centered on the window
  • Save game geometry - ensures that the game window size and position are preserved on reloading
  • Keep dialogs on top - dialog windows, like find card or help, will always remain on top of the game window

Animations

From here, you can set the animation speed, turn off animations entirely, or toggle specific animations (redeal, flip, and winning animations)

Mouse

From mouse options, you can decide how the mouse will work in the app, if you want to move cards by drag and drop, point and click, or a sticky mouse.

Additionally, you can turn on whether to use the unique drag card cursor or if you want to enable the mouse shortcuts for undo and redo (described in How to use PySol).

Fonts, Colors, and Timeouts

Here, you can alter the fonts and text styles used throughout the app, or the colors in the game. By changing timeouts, you can speed up or slow down the delay between certain automatic actions.

Window Theme

The window theme determines the look and feel of PySol's main window and the various dialogs.

Toolbar and Status Bar

You can configure the toolbar on the top of the window. From here, you can turn on and off the toolbar or move it to a different side of the screen.

Additionally, you can decide which icons you want to have on the toolbar. You can control the toolbar configuration - the size and style of the icons, or if the icons are displayed with labels.

Similarly, you can turn on or off the status bar at the bottom of the window, and determine which pieces of info will be shown in the status bar.

Other Graphics

From the other graphics options, you can configure the style of pretty much any of the secondary graphics in PySol, such as the game paused text, the demo logo, the dialog, tree, and redeal icons, or icons on the dialog buttons.

Where Settings are Stored

PySol settings are stored in a configuration file, options.dat or options.cfg depending on your environment - this file is located in the user folder. See Installation for more details on the exact pathing.

You may back up this file, but editing it manually is not recommended and can break your configuration.
